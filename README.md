# 🛵 واتس هم (WhatsHam) — منصة طلبات المطاعم عبر واتساب

منصة متكاملة تدير **المطاعم، المنيو، العروض، الإعلانات، الولاء، الطلبات عبر واتساب، فريق التوصيل، والدفع** — من أول رسالة من العميل حتى تقييمه بعد الاستلام.

---

## ✨ المميزات (كل ما طلبته)

| الميزة | كيف تعمل |
|---|---|
| 🏪 **المطاعم والفروع** | إضافة مطاعم، ولكل مطعم **فروع** وكل فرع له **نطاق توصيل (زوم)** ورسومه وحدّه الأدنى |
| 🍽 **الأقسام والأصناف** | لوحة المطعم: إضافة/تعديل/إيقاف أقسام وأصناف بالصور والأسعار |
| 🔥 **العروض** | نسبة % أو مبلغ ثابت أو باقة، مع حد أدنى للطلب |
| 📣 **برنامج الإعلانات** | حملات إعلانية (ميزانية، مشاهدات، نقرات) تظهر في رسالة واتساب الترحيبية |
| ⭐ **نظام الولاء** | نقطة لكل ريال، مستويات (برونزي/فضي/ذهبي/بلاتيني)، رصيد النقاط يظهر للعميل |
| 📍 **الموقع والعنوان الوطني** | العميل يرسل موقعه عبر واتساب → يُحفظ في قاعدة البيانات → **في المرة القادمة يُسأل**: "هل يصلك على عنوانك الوطني السابق أم مكان آخر؟" |
| 🚫 **نطاق التوصيل** | إذا كان الموقع **خارج زوم** كل الفروع → البوت **يعتذر عن التوصيل** ويقترح أقرب فرع |
| 🏪 **أقرب فرع** | عند إرسال الموقع يُربط الطلب تلقائياً **بأقرب فرع** (رسومه ونطاقه) |
| 💳 **الدفع** | Apple Pay / مدى / بطاقة عبر بوابة **مويصر** (أو وضع تجريبي بدون إعدادات) |
| 📦 **الطلبات عبر واتساب** | تصفح المنيو → سلة → دفع → موقع → عنوان → وقت توصيل → طلب — كله برسائل واتساب (قوائم وأزرار تفاعلية) |
| 🔐 **رمز الاستلام** | النظام يرسل للعميل **رمز 6 أرقام**، يسلّمه للمندوب عند الاستلام، والمندوب يرسله **لواتساب المطعم** فيُغلق الطلب |
| 🛵 **التوزيع على الكباتن** | الطلب يُرسل **لكل الكباتن المتاحين**، من يقبل يظهر للمطعم، والمطعم **يحوّل الطلب عليه** عبر لوحة التحكم |
| 📱 **إبلاغ الوصول** | من جوال المندوب: "وصلت" → العميل يستلم إشعار "📍 وصل كابتن التوصيل! طلبك عند الباب" |
| ⭐ **التقييم** | بعد التسليم يقيّم العميل: المطعم + السرعة + الكابتن + تعليق → **الكابتن يستلم رسالة بتقييمه** |
| 💬 **حفظ المحادثات** | **كل المحادثات من بداية الطلب حتى التقيم** محفوظة في حساب الكابتن والمطعم والكنترول |
| ⚡ **لحظي** | إشعارات فورية عبر Socket.IO لكل الأطراف |

## 🚀 التشغيل السريع

```bash
# 1) التثبيت
npm run install:all

# 2) البيانات التجريبية
npm run seed

# 3) التشغيل (السيرفر + الواجهة)
npm run dev:server   # في طرفية  → http://localhost:4000
npm run dev:client   # في طرفية  → http://localhost:5173
```

أو للتشغيل النهائي بدون طرفيتين:
```bash
npm run build && npm start
# السيرفر يخدم الواجهة كاملة على http://localhost:4000
```

## 🧪 تجربة الدورة الكاملة (5 دقائق)

1. افتح **محاكي الواتساب** (`/sim`) → اضغط "👋 ابدأ".
2. أرسل اسمك → تصفح القائمة → أضف صنفاً → إتمام الطلب → اختر الدفع → ✅ تم الدفع.
3. أرسل الموقع (زر "📍 موقع داخل الزوم") → حدد وقت التوصيل.
4. 📲 استلم **رمز الاستلام** في رسالة التأكيد.
5. افتح **لوحة المطعم** → الطلب يظهر → أكّده → حوّله للكابتن الذي قبله.
6. افتح **لوحة الكابتن** → اقبل العرض → استلمت الطلب → انطلقت → وصلت.
7. أرسل رمز الاستلام لواتساب المطعم (جرّبه من الترمينال):
   ```bash
   curl -X POST http://localhost:4000/api/whatsapp/captain-message \
     -H 'Content-Type: application/json' \
     -d '{"captain_phone":"0561111111","body":"رمز 123456"}'
   ```
8. العودة للمحاكي: قيّم المطعم والسرعة والكابتن → الكابتن يستلم تقييمه، والعميل يكسب نقاط ولاء.

## 🔌 الربط مع واتساب الحقيقي (WhatsApp Cloud API)

1. أنشئ تطبيقاً في [developers.facebook.com](https://developers.facebook.com) → منتج WhatsApp.
2. احصل على `WHATSAPP_TOKEN` و `WHATSAPP_PHONE_NUMBER_ID`.
3. ضعها في `.env` واضبط `WHATSAPP_PROVIDER=cloud`.
4. فعّل الويب هوك على الرابط:
   ```
   https://نطاقك/api/whatsapp/webhook
   ```
   مع رمز التحقق `WHATSAPP_VERIFY_TOKEN`.

النظام يرسل: نصوص، أزرار تفاعلية، قوائم، صور — ويستقبل: نصوص، مواقع، ضغط الأزرار.
رسائل المندوبين (رمز الاستلام) تُلتقط تلقائياً من نفس الرقم وتُغلق الطلب.

## 💳 الدفع الحقيقي (Apple Pay + مدى)

1. سجّل في [dashboard.moyasar.com](https://dashboard.moyasar.com) (يدعم Apple Pay ومدى في السعودية).
2. ضع المفاتيح في `.env` واضبط `PAYMENT_MODE=moyasar`.
3. الويب هوك: `https://نطاقك/api/payments/webhook/moyasar`.

الوضع التجريبي (`mock`) يؤكد الدفع تلقائياً بعد ثانيتين — مناسب للتجربة.

## ☁️ النشر

- **أبسط خيار:** [Railway.app](https://railway.app) أو [Fly.io](https://fly.io) — ارفع مجلد `server` واضبط `BUILD` ثم `node index.js`، وارفع `client/dist` كملفات ثابتة أو استخدم `npm run build` في نفس الخدمة.
- **VPS:** `npm run build && npm start` + Nginx عكسي، و`PUBLIC_URL` = نطاقك.

> ⚠️ قاعدة البيانات SQLite محلية (`server/data/wassal.db`) — للنشر الحقيقي ركّب **PostgreSQL** بدلاً منها (الكود مفصول بالخدمات ويسهل استبداله).

## 🏢 سلسلة مطاعم — لوحات مستقلة للفروع

- **المطعم الرئيسي** (حاشي باشا): يرى كل الفروع، يدير المنيو المشترك والعروض، ينشئ حسابات الموظفين.
- **مشرف الفرع**: لوحة مستقلة — طلبات فرعه فقط + إعدادات فرعه (نطاق التوصيل/الرسوم) + تقارير فرعه.
- **مدير الجودة**: تقييمات العملاء (مطعم/سرعة/كابتن) + مدى وصول الطلبات + التقارير.
- **الكاشير**: طلبات الفرع فقط — **بدون تقارير**.

### 📋 التقارير (طباعة / PDF)
كل من المشرف ومدير الجودة والمطعم الرئيسي يطبعون تقارير: **يومي / أسبوعي / شهري / ربع سنوي (3 أشهر) / نصف سنوي (6 أشهر) / سنوي** — تشمل: الطلبات، الإيراد، متوسط التقييمات، مدى وصول الطلبات (% وصلت وسُلّمت)، طرق الدفع، الأصناف الأكثر طلباً، وجدول تفصيلي قابل للطباعة.
